# FoodCatalyst Streamlit App

This document provides an overview of the `app.py` file, which is the Streamlit user interface for the FoodCatalyst project.

## 🚀 Running the App

To run the Streamlit app, make sure you have all the dependencies installed (as described in the main `README.md`), and then run the following command in your terminal:

```bash
streamlit run app.py
```

## 📋 Features

The Streamlit app provides the following features:

- **User-friendly Interface**: A clean and intuitive interface for users to input their dining preferences.
- **Personalized Recommendations**: Leverages the power of `crewAI` to generate personalized restaurant recommendations.
- **Dynamic UI**: The UI is built with Streamlit, which allows for interactive components and a responsive design.
- **Sidebar for Inputs**: A well-organized sidebar for users to input their preferences, including:
    - Cuisine/Food Type
    - Location
    - When to Dine
- **Advanced Settings**: An expandable section for advanced settings, such as the current year for the AI model.
- **Informative Sections**: Expandable sections in the sidebar provide information about how the app works, tips for users, featured cuisines, and popular cities.
- **Main Content Area**: A simple and clean main content area that displays the input form and the results.
- **Restaurant Cards**: The results are displayed in visually appealing cards, each containing:
    - Restaurant Name
    - Rating
    - Cuisine
    - Location
    - A detailed analysis from the AI
    - A "Google Search" button to easily find the restaurant on Google.
- **Error Handling**: The app includes user-friendly error messages if the AI fails to generate a valid response.
- **HTML Report**: If an HTML report is generated by the `crewAI` agents, it is displayed within the app.

## ⚙️ Code Overview

The `app.py` file is structured as follows:

1.  **Imports**: Imports necessary libraries like `streamlit`, `os`, `sys`, `json`, `datetime`, `re`, and `dotenv`.
2.  **Environment Setup**:
    - A workaround for `pysqlite3` in cloud environments.
    - Loads environment variables from a `.env` file.
    - Adds the `src` directory to the system path to allow importing the `FoodCatalyst` crew.
3.  **Page Configuration**: Sets the page title, icon, layout, and initial sidebar state.
4.  **CSS Styling**:
    - A function `local_css` to load a local `style.css` file.
    - Custom CSS is also defined directly in the app for specific components like the header and restaurant cards.
5.  **Header and Introduction**: Displays the main header and a brief introduction to the app.
6.  **Sidebar**:
    - Collects user inputs for `topic`, `location`, and `date_option`.
    - Includes expandable sections for "Advanced Settings", "How It Works", "Tips", "Featured Cuisines", and "Popular Cities".
7.  **Main Content Area**:
    - Displays a subheader and a form for user inputs.
    - The form includes fields for cuisine, location, and date, which are pre-filled with the values from the sidebar.
    - A "Discover Restaurants" button submits the form.
8.  **Form Submission Processing**:
    - When the form is submitted, it checks if the required inputs are provided.
    - It then displays an info message and kicks off the `FoodCatalyst` crew with the user's inputs.
    - The result from the crew is parsed (expecting a JSON string).
    - If the parsing is successful and an itinerary is found, it displays the restaurant recommendations in cards.
    - If parsing fails or no itinerary is found, it displays an appropriate error message.
    - It also displays the `report.html` file if it exists.
9.  **Footer**: A simple footer with a "Powered by crewAI" message.
